# Modelo _q_-Votante e ordem superior

**Aluno:** Timóteo Fassoni
**Orientador:** Silvio Ferreira
**Coorentador:** Wesley Cota

Dinâmica de opiniões, o estudo de como crenças individuais e opiniões públicas evoluem, é um domínio fértil de estudo da Física Estatística. Assim como diversos sistemas físicos, a sociedade também apresenta um comportamento que, partindo das interações locais, leva a resultados globais como consenso ou fragmentação de ideias. Neste seminário, partindo de um panorama sobre modelos do tipo Votante, abordaremos um modelo não-linear de opiniões, o _q_-Votante, apresentando resultados de teoria de campo médio, simulações em redes e efeitos de topologia.
